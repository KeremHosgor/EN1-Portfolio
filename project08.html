Project 8: Astronaut Tools

The astronaut tool did not work as intended because the nuts would not move; the gray mills were too wide.

Python Code:

# Motor is connected to port C.
# The Force Sensor is connected to port D.
from hub import port
import runloop
import motor
import force_sensor

# Set the motor's maximum speed in degrees per second.
MAX_SPEED = 660

async def main():
    # Set the direction for the first press.
    direction = 1
    was_pressed = False

    # Keep checking the Force Sensor.
    while True:
        pressed = force_sensor.pressed(port.D)

        if pressed:
            # Reverse direction when a new press begins.
            if not was_pressed:
                direction = -direction

            # Set the motor speed based on how hard the sensor is pressed.
            force = force_sensor.force(port.D)
            speed = int(force * MAX_SPEED / 100)

            # Run the motor in the selected direction.
            motor.run(port.C, direction * speed)
        else:
            # Stop the motor when the sensor is released.
            motor.stop(port.C)

        # Remember the press state for the next check.
        was_pressed = pressed

        # Wait briefly before checking the sensor again.
        await runloop.sleep_ms(20)

runloop.run(main())

What the Code Does

The code repeatedly checks the Force Sensor on port D. When the sensor is pressed, the motor on port C runs; pressing harder increases its speed, up to the maximum of 660 degrees per second. The motor reverses direction each time a new press begins and stops when the sensor is released. The short wait lets the program check the sensor again. This controls the motor, but it cannot make the nuts move if the tool's gray mills are too wide to grip them.
